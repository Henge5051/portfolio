# 📊 Портфель — Telegram Mini App

Личный трекер инвестиций, CS2-скинов, кейсов и трейдинга.

## Возможности
- 💼 Инвестиции (акции, ETF, крипта)
- 🎮 CS2 Скины
- 📦 CS2 Кейсы
- 💹 Трейдинг (Long/Short)
- ⚖️ Диверсификация
- ☁️ Синхронизация через Supabase
- 🤖 Telegram-бот

## Деплой
- Frontend: GitHub Pages
- Backend: Render
